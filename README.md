🗑️ Basura al Cubo
🎮 Descripción

Basura al Cubo es un videojuego 2D interactivo desarrollado con tecnologías web (HTML, CSS, JavaScript y Canvas API), cuyo objetivo es concientizar al usuario sobre la recolección de basura y el cuidado del medio ambiente mediante una experiencia dinámica y entretenida.

El jugador debe recolectar distintos tipos de residuos haciendo clic sobre ellos, evitando objetos peligrosos y gestionando su nivel de salud mientras avanza en dificultad.

🎯 Objetivo del Juego

Recolectar la mayor cantidad de basura posible para obtener puntos, evitando objetos peligrosos que reducen la salud del jugador.

🧠 Mecánicas del Juego
🖱️ Interacción mediante clic del mouse
🗑️ Recolección de basura para sumar puntos
⚠️ Objetos peligrosos que reducen la salud
❤️ Botiquines que recuperan vida
📈 Sistema de niveles progresivos
🧮 Registro de puntuación y récord
⚙️ Tecnologías Utilizadas
HTML5 → Estructura de la aplicación
CSS3 → Estilos, animaciones y diseño visual
JavaScript (ES6) → Lógica del juego
Canvas API → Renderizado y animación 2D
Bootstrap 5 → Diseño responsivo e interfaz
🎨 Características
🎮 Juego interactivo en tiempo real
🌆 Fondo visual dentro del canvas
🖱️ Cursor personalizado
💥 Animaciones de impacto al hacer clic
🔥 Efectos visuales (fuego al caer objetos)
🧠 Guardado de récord con localStorage
🏁 Pantalla final tipo arcade
📱 Interfaz moderna y responsiva
🕹️ Cómo Jugar
Inicia el juego presionando "Comenzar Juego"
Haz clic sobre los objetos que aparecen en pantalla:
🗑️ Basura → suma puntos
🗑️ Bolsa de basura → más puntos
⚠️ Objetos peligrosos → pierdes vida
❤️ Botiquín → recuperas vida
Evita que la basura caiga al suelo
Sobrevive el mayor tiempo posible
Supera tu récord
🏁 Fin del Juego

El juego termina cuando la salud llega a 0.
Se mostrará una pantalla final con:

Puntaje obtenido
Récord alcanzado
Opción para reiniciar
